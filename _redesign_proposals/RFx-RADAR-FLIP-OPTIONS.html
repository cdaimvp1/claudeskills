Model The Decision, Flipped Radar: Category Spokes, Supplier Polygons

The old radar put suppliers on the eight spokes of an eight-sided frame, so with three suppliers scored today the drawn shape was a tiny triangle lost inside a large octagon. This flips it: the eight spokes are always the eight requirement categories from the filed weighting model, so the frame is always full regardless of how many suppliers are scored, and each supplier is now one colored polygon tracing its per-category fit across those eight spokes. Spokes and polygons are generated in a loop from the categories and suppliers arrays, not hardcoded to eight and three.
Reading the data: Nimbus Data holds the top panel score (4.4 of 5) at $980,000/yr but its SOC 2 report is Type I against a filed Must-Have Type II gate, so it is excluded from the ranking regardless of the weights below. Lakehouse Co (4.2 of 5, $1,060,000/yr) clears every Must-Have. Helio Warehouse (3.2 of 5) has the strongest SAP integration on file but submitted NEEDS_INPUT: no price, no MSA, no implementation plan. The eight per-category fit percentages plotted on the radar below are computed directly from each supplier's per-requirement response-analysis scores (the platform's rfxCatFit: category weight × score ÷ category weight × 5), not invented for this exploration; the "weighted score" shown in each legend updates live as the category-weight sliders move and is a modeled figure, not a submitted one.
Canonical Supplier Color Palette (Reuse Dashboard-Wide)
One fixed color per supplier position, anchored in the MCM palette, harmonious and distinguishable at up to eight suppliers. Positions 1–3 are byte-identical to the existing PVVENDOR_COLORS rotation in supplier-landscape-1c344a/dashboard/assets/pv/pv-07-landscape-render.js (plum / teal / burnt-orange), so this set is a drop-in extension of what already ships, not a competing scheme. Positions 7–8 reuse that same file's existing plum-mauve and deep-amber tint extensions for the same reason. Assign by supplier index, in submission order; a supplier keeps its color everywhere it appears (Landscape, RFx, Deal).

Requirement-Category Fit Radar
Each polygon is one supplier's fit across the eight filed requirement categories (0–100%), from the response analysis; the shape itself does not move when the sliders change, only the weighted totals at right do.
A supplier that fails a Must-Have gate is excluded from the ranking regardless of the weights, a gate failure is weight-invariant; its polygon still plots on the radar so its per-category shape stays comparable, it is simply never awardable on today's evidence.
